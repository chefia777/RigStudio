# Sprite Rig Studio — Keyboard Shortcuts

## Project

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Shift+S` | Save As |

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Delete` | Delete selection |
| `Escape` | Cancel active operation |

## Tools

| Shortcut | Tool |
|---|---|
| `W` | Move (translate) tool |
| `R` | Rotate tool |
| `E` | Scale tool |
| `M` | Mask tool |
| `P` | Pivot tool |
| `A` | Anchor tool |
| `Space` | Select tool |

## Viewport

| Shortcut | Action |
|---|---|
| `F` | Fit artwork in viewport |
| `Ctrl+0` | Reset zoom |
| `Middle mouse drag` | Pan viewport |
| `Mouse wheel` | Zoom around cursor |
| `Ctrl+Plus` | Zoom in |
| `Ctrl+Minus` | Zoom out |

## Animation

| Shortcut | Action |
|---|---|
| `Space` | Play / Pause preview |
| `Left arrow` | Previous frame |
| `Right arrow` | Next frame |
| `Shift+Left` | Previous keyframe |
| `Shift+Right` | Next keyframe |

## View

| Shortcut | Action |
|---|---|
| `Ctrl+1` | Project panel |
| `Ctrl+2` | Inspector panel |
| `Ctrl+3` | Timeline |

Shortcuts are centralized in `src/SpriteRigStudio.Desktop/Input/KeyboardShortcuts.cs`.
